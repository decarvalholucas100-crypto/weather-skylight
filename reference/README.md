# Reference photos

Real sky photos taken **straight up** (lying on your back, phone pointed at the zenith), one per
scenario in `tools/scenarios.json`, named as that file's `reference` field:

- `clear-midday.jpg`, `broken-cumulus.jpg`, `overcast.jpg`, `low-sun-backlit.jpg`,
  `golden-hour.jpg`, `moonlit-thin-cloud.jpg`

Photos in this folder are gitignored (only this README is tracked) so licensing never becomes a
question. Use your own photos or CC0 images. `tools/capture.mjs` places them in the left panel of
each composite next to the baseline and current render.
